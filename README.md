# ARDA FAMILY

Website silsilah dan arsip keluarga Arda.

## Struktur

- **Arda** ditempatkan sebagai **Family Root / Generasi 0** untuk navigasi website.
- Posisi root tidak berarti Arda adalah leluhur tertua.
- Jalur keluarga yang belum diketahui tidak dibuat-buat.
- Leluhur dapat dicatat lebih dulu di bagian **Arsip Leluhur** sambil menunggu hubungan antargenerasi terverifikasi.

## Update data keluarga

Data utama berada di `family-data.js`.

## Deployment

Static site, kompatibel dengan Cloudflare Pages.

- Build command: kosong
- Build output directory: `/`
- Production branch: `main`

Target domain yang direkomendasikan: `ardafamily.nadmo.id`.
